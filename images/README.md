# images फोल्डर

एडिटरमधून (`…/#edit` → **पार्श्वभूमी व चित्रे**) चित्र निवडून **GitHub वर प्रकाशित करा** दाबल्यावर ती चित्रे आपोआप या फोल्डरमध्ये जमा होतात. तुम्हाला आकार बदलावा लागत नाही. संगणक आणि मोबाईलसाठी योग्य आकाराची प्रत एडिटर स्वतः बनवतो.

| फाइल | काय आहे | आपोआप बनणारा आकार |
|---|---|---|
| `background.jpg` | सर्व पानांची पार्श्वभूमी (संगणक) | जास्तीत जास्त २००० px |
| `background-mobile.jpg` | तीच पार्श्वभूमी (मोबाईल) | उभी ९:१६, १६०० px उंच |
| `cover.jpg`, `cover-mobile.jpg` | पहिल्या पानाची वेगळी पार्श्वभूमी | वरीलप्रमाणे |
| `envelope.jpg`, `envelope-mobile.jpg` | लखोट्याची पार्श्वभूमी | वरीलप्रमाणे |
| `edge.png` | बाजूची सजावट (पारदर्शक PNG) | ३०० px रुंद |
| `couple.jpg` | जोडप्याचा फोटो | १००० px |
| `venue.jpg` | स्थळाचा फोटो | १२०० px |
| `gallery-….jpg` | गॅलरीचे फोटो | ९०० px |

## चित्र निवडण्याच्या सूचना
- पार्श्वभूमीसाठी मध्यभागी महत्त्वाचा भाग असलेला फोटो निवडा. मोबाईलवर मधला उभा भाग दिसतो.
- मजकूर वाचायला अवघड वाटल्यास एडिटरमध्ये ‘हलका पडदा’ वाढवा.
- बाजूच्या सजावटीसाठी उभी, पारदर्शक PNG (उदा. १२० × ६०० px) वापरा. ती वर-खाली पुन्हा पुन्हा लागते.

## स्वतः फाइल बदलायची असेल तर
GitHub मध्ये **Add file → Upload files** ने **तेच नाव** असलेली फाइल या फोल्डरमध्ये टाका. नवीन चित्र दिसायला काही मिनिटे लागू शकतात.
